# Zustand
Trong dự án sẽ dùng zustand để trao đổi dữ liệu giữa các component với nhau hoặc để lưu trữ state cho sử dụng cho việc khác

## 1. Khai báo
Tạo file với tên là `Chức năng + Store` trong thư mục `stores`. Ví dụ:
```
📦stores
 ┣ 📜tokenStore.ts
 ┣ 📜userStore.ts
```

Trong file tokenStore sẽ có nội dung như sau:
```tsx
import { EAccountRole, IAccountInfo } from '@/types/common';
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import cookieStorage from './storages/cookieStorage';
import { useUserStore } from './userStore';

export interface TokenStoreState {
  accessToken?: string;
  refreshToken?: string;
  role?: EAccountRole;
}

interface TokenStore extends TokenStoreState {
  loginUser: (account: IAccountInfo) => void;
  logoutUser: () => void;
}

export const useTokenStore = create<TokenStore>()(
  persist(
    set => ({
      loginUser: account => {
        set({
          accessToken: account.accessToken,
          refreshToken: account.refreshToken,
          role: account.user?.role?.id,
        });
        useUserStore.getState().updateUser(account);
      },
      logoutUser: () => {
        set({
          accessToken: undefined,
          refreshToken: undefined,
          role: undefined,
        });
        useUserStore.getState().clearUser();
      },
    }),
    {
      name: 'token-storage',
      storage: createJSONStorage(() => cookieStorage),
    },
  ),
);

```

`Lưu ý:  Chỉ dùng wrapper persist nếu cần lưu lại dữ liệu người dùng sau khi tắt webpage`

Trong file userStore sẽ có nội dung như sau:

```
import { IAccountInfo } from '@/types/common';
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

const defaultState: IAccountInfo = {
  user: undefined,
  isConfirmed: false,
  dataProfile: undefined,
};

interface UserStore extends IAccountInfo {
  updateUser: (account: IAccountInfo) => void;
  clearUser: () => void;
}

export const useUserStore = create<UserStore>()(
  persist(
    set => ({
      updateUser: account =>
        set({
          user: account.user,
          isConfirmed: account.isConfirmed,
          dataProfile: account.dataProfile,
        }),
      clearUser: () => set({ ...defaultState }),
    }),
    {
      name: 'user-storage',
    },
  ),
);

```

`Lưu ý:  Chỉ dùng wrapper persist nếu cần lưu lại dữ liệu người dùng sau khi  tắt webpage`

## 2. Thay đổi state trong store

```tsx
const { loginUser, logoutUser } = useTokenStore();

loginUser({
    user: {
      fullName: 'Tinasoft',
      email: 'tina@tinasoft.com.vn',
      avatar: '/img/avatar/avatar.jpg',
      role: {
        roleName: 'user',
        id: 0,
      },
    },
    accessToken: 'some hashed string',
    refreshToken: 'some refresh token',
  });
```

## 3. Lấy state trong store

```tsx
 const { user } = useUserStore();
```
